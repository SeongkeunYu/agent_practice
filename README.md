# Bowling Kata

TDD 연습을 위한 미국식 텐핀 볼링 점수 계산기입니다.

## 목표

Red → Green → Refactor 사이클을 반복하며 볼링 점수 계산 로직을 단계적으로 구현합니다.

## 문제 설명

한 게임(10프레임)의 투구 결과가 주어졌을 때 최종 총점을 계산합니다.

### 점수 규칙

| 상황 | 조건 | 보너스 |
|------|------|--------|
| 일반 | 두 투구 합산 < 10 | 없음 |
| 스페어 | 두 투구로 핀 10개 전부 | 다음 투구 1회 핀 수 |
| 스트라이크 | 첫 투구로 핀 10개 전부 (1회로 프레임 종료) | 다음 투구 2회 핀 수 합계 |

10번 프레임에서 스페어·스트라이크를 기록하면 최대 3투구까지 가능합니다.

### 점수 예시

| 게임 | 설명 | 점수 |
|------|------|------|
| 거터 게임 | 20구 모두 0 | 0 |
| 모두 1핀 | 20구 모두 1 | 20 |
| 스페어 1개 | 5+5, 이후 3 → 나머지 0 | 16 |
| 스트라이크 1개 | 10, 이후 3+4 → 나머지 0 | 24 |
| 퍼펙트 게임 | 12구 연속 스트라이크 | 300 |
